# JLC06161H-3313 standard construction

Reusable source-backed data for nominal 1.6 mm six-layer FR4, outer 1 oz and
inner 0.5 oz. Retrieved official HTML is retained in ignored
`cache/stackup-20261010/`; hashes and table locators are in `stackup.json`.

Consumers select the profile explicitly. This is companion qualification data,
not a Copper module, a layer-function prescription, or production approval.
Algorithms belong in CopperScript; net/reference bindings belong in the board.
Do not stretch the published dielectric thicknesses to reach nominal thickness,
substitute an average plating value for a minimum, or invent loss tangents.

Sources: [stackup](https://jlcpcb.com/impedance) and
[capabilities](https://jlcpcb.com/capabilities/pcb-capabilities).
