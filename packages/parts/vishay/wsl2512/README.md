# WSL2512R0500FEA

Two-terminal 50 mΩ, 1%, 1 W at 70 °C resistor; component TCR ±75 ppm/°C.
Source: [Vishay 30100](https://www.vishay.com/docs/30100/wsl.pdf), revision
23-Nov-2023, pages 1–2. Do not substitute the four-terminal WSK family.
Set the consumer's resistor value to `0.05 ohm`.

The footprint uses the published metric lands for 0.007–0.5 Ω: each
1.65 × 3.68 mm, inner gap 4.06 mm, centres ±2.855 mm. Sense traces must
branch from the inner land edges independently of load-current copper.
The board owns Kelvin topology and current/thermal qualification.
Manufacturer stencil recommendations and factory assembly review remain open.
