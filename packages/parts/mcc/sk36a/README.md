# sk36a

Exact reusable part interface and manufacturer package mapping for MCC SK36A-LTP (SK36A-L, SMA/DO-214AC, 60 V 3 A Schottky). Source: [SK32A-L thru SK310A-L Rev.4-1-04222024, p1 ratings, pin description and suggested pad layout](https://www.mccsemi.com/pdf/products/SK32A-L-SK310A-L(SMA).pdf). The source identity is in `evidence/source.json`.

Pin 1 is the cathode (marked band) and pin 2 the anode, matching KiCad Diode_SMD:D_SMA.

Use the exact named orderable part. Ratings and topology remain subject to the manufacturer operating conditions. This addition establishes pin/package source facts, not current capacity, thermal, transient, EMC, assembly or hardware qualification. The consumer owns operating conditions and procurement selection.
