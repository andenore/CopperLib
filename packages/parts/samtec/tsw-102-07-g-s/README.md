# TSW-102-07-G-S

Two-position, single-row, 2.54 mm through-hole Samtec header. Pin 1 is the square
land at the footprint origin. Samtec's recommended PCB layout revision A calls
for 1.02 mm holes; 1.7 mm lands are an engineering adaptation. Verify finished
hole tolerances, annular rings and factory placement origin before ordering.

Use the matching SNT-100-BK-G for a removable bypass. Samtec rates the SNT/TSW
system at 4.3 A per pin with one pin powered per row; an arbitrary jumper-wire
contact does not inherit that rating. Contact resistance still needs measurement.

Sources and source hash are in `evidence/manifest.json`.
