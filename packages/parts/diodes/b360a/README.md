# b360a

Exact reusable part interface and manufacturer package mapping for Diodes Incorporated B360A-13-F (60 V, 3 A Schottky rectifier, SMA/DO-214AC). Source: [DS13005 Rev. 9-2, p1 ratings and package](https://www.diodes.com/assets/Datasheets/ds13005.pdf). The source identity is in `evidence/source.json`.

Pin 1 is the cathode (marked band) and pin 2 the anode, matching KiCad Diode_SMD:D_SMA. Same package, pinning and 60 V / 3 A rating as MCC SK36A-LTP (`parts/mcc/sk36a`).

Use the exact named orderable part. Ratings and topology remain subject to the manufacturer operating conditions. This addition establishes pin/package source facts, not current capacity, thermal, transient, EMC, assembly or hardware qualification. The consumer owns operating conditions and procurement selection.
