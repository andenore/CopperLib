# RClamp1561PQTCT transmitting RF protection candidate

Manufacturer-authored Rev2.1, July24 2017, obtained through the public LCSC
datasheet iframe, is hash-bound in part.copper and qualification.json.
Body: 1000 x 600 um; electrically symmetric two-terminal device. Its p6
reference land pattern has 550 x 600 um lands on 850 um centers; the local
footprint rotates that drawing. Manufacturer manufacturing/process review
is still required, including confirming current applicable revision.

Working voltage: bidirectional 15 V. Capacitance: 250 fF typical / 300 fF
maximum **at 15 V bias and 1 MHz**. Neither value is an unbiased maximum.
Clamp: up to 35 V at 2 A, 8/20 us; TLP examples reach 76 V at 16 A.
The device rating is not a claim that the protected modem survives system ESD.
Evaluate mismatch peaks, unbiased RF loading, harmonics and return inductance.

Exact Semtech JLCPCB candidate C20336388; no same-name clone substitution.
Live assembly inventory, installed RF performance and system ESD remain open.
